# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use the repository's private security advisory reporting feature, or contact the project maintainers privately through the repository's contact channel.

Include a clear description of the issue, affected components, steps to reproduce, and any suggested mitigation. We will acknowledge the report and work with you on a resolution.

## Supported versions

Security fixes are applied to the latest version on the `main` branch.
